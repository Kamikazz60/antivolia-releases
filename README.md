# AntivolIA — téléchargements

Alarme antivol pour smartphone Android : une sirène retentit si le téléphone est déplacé ou si le chargeur est débranché, et ne s'arrête qu'avec le code PIN. Aucun compte, aucune publicité, aucune télémétrie, **aucune permission Internet**.

Ce dépôt ne contient que les **versions installables (APK)**, dans l'onglet [Releases](../../releases). Le code source n'est pas publié.

Fiche détaillée, permissions et contrôle de sécurité : https://kamikazz60.github.io/Mon-Android-Store/#/app/antivolia

- Android 10 ou plus récent.
- Vérifiez l'empreinte SHA-256 donnée dans les notes de chaque Release.
